# Components Folder

This folder is reserved for future React components.

When migrating to React/Next.js, reusable UI pieces can be extracted here:

- `Navbar.jsx` — Navigation bar
- `Footer.jsx` — Site footer
- `ProductCard.jsx` — Product listing card
- `CategoryCard.jsx` — Category display card
- `FilterBar.jsx` — Marketplace filters
- `ProductForm.jsx` — Sell item form

The current HTML structure mirrors what these components will become.
